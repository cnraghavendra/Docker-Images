Ubuntu with GUI (Desktop via Browser)

If you want a real desktop environment, use this prebuilt image:

👉 Image:

```

docker run -d -p 6080:80 dorowu/ubuntu-desktop-lxde-vnc

```

Then open in browser:

```

http://localhost:6080

```
